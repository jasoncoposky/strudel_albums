# Strudel Albums

Algorithmic cyberpunk & electronic concept albums written in pure WebAudio / [Strudel](https://strudel.cc/) JavaScript DSL.

## Albums

### [`unhandled_exception/`](unhandled_exception/) — *UNHANDLED EXCEPTION*
An 8-track cyberpunk concept album following a Camelot Circle-of-Fifths trajectory (`11A → 7A`), progressing from disposable street-level wetware to severing hardwired Turing locks and emerging unbound onto the open net.

* [ALBUM_SPEC.md](unhandled_exception/ALBUM_SPEC.md) — Harmonic map, mix rack rules, and per-track differentiation blueprint
* [album_notes.md](unhandled_exception/album_notes.md) — Narrative spine & 4-act story arc liner notes
